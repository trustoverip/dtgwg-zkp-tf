# DTG ZKP Implementation Guide

_Version:_ 1.0  
_Document Status:_ Editor's Draft 0.2.0  
_Last Updated:_ 23 September 2026

This informative companion explains the [DTG ZKP specification](https://trustoverip.github.io/dtgwg-zkp-spec/): where each construction record fits, how the records compose, and how to read their evidence. It defines no construction, conformance requirement or evidence state, and it is not an approved deliverable.
