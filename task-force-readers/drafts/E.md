**Title:** Add AGENT-RUNTIMES.md and link the evidence repository

Adds a companion to `DRAFTING-RULES.md` describing how task-force members and their AI assistants can back a position with runnable evidence, and links the public evidence repository (github.com/mitchuski/dtgwg-zkp-mage — discussion #14) from the README.

What the document does:
- names the evidence repository's lanes in one line each (per-predicate runtimes, real circuits with published numbers, a conformance-fixture format, a verification registry, and the board cards for #18) and why each matters to the task force;
- states the working practice's three rules — the assistant operates, the member decides; disclose the assistant; say only what the tests hold — so they can be held to;
- draws the path from a discussion to a runnable claim, marking where a person must stand (posting, seat admission, publication);
- says what it is not: not a construction selection, not an audit, not a requirement on anyone.

Scope: two files, docs only (`AGENT-RUNTIMES.md` new; `README.md` +1 line under *Where to start*, +1 section *Evidence and reference runtimes*). No change to the requirements document or the drafting rules. Same IPR posture as the repository (CC BY 4.0).

Offered open-source style: the evidence repository is not a dependency of this one and never will be; it is one member's method, shared into the fold so others can run it, refute it, or replace it through the same gate.

Disclosure: drafted with an AI assistant from the co-chair's working record; reviewed and submitted by the co-chair.
